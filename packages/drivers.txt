# Driver packages for the offline repo on the USB stick.
# During installation `chwd --autoconfigure` picks the right profile for the
# hardware and installs from this repo, exactly as CachyOS would online.
#
# Source: CachyOS chwd, profiles/pci/graphic_drivers/profiles.toml.
# scripts/fetch-offline-repo.sh warns if a chwd profile needs something missing here.

# "pkg?" = optional: skipped with a warning if the repos do not have it.
# Only graphics profiles are installed offline (celestia-configure runs chwd per
# display class); other hardware can be configured online later: sudo chwd -a
