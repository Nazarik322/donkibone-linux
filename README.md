# Celestia

Celestia — это **CachyOS** (её ядро, драйверы и оптимизации без изменений) с красивым рабочим
столом [caelestia](https://github.com/caelestia-dots/caelestia) на Hyprland. Оформление самой
CachyOS убрано. Ставится как Windows: загрузился с флешки → выбрал, куда ставить → имя и
пароль → готово. Интернет при установке не нужен.

Рядом с Windows работает без проблем. При каждом включении компьютера:

1. **Меню выбора системы.** Через 5 секунд загружается **Windows**; стрелками ← → выбираешь
   **Celestia** и жмёшь Enter. Если Windows на компьютере нет, сразу грузится Celestia.
2. **Экран блокировки Celestia.** Вводишь пароль — и ты на рабочем столе.

> **О проекте.** Весь код и эта инструкция написаны нейросетью (Claude от Anthropic) по запросам
> автора. Автоматические проверки есть, но на реальных компьютерах система тестировалась мало.
> Перед установкой сделай резервную копию важных файлов.

---

## 1. Что нужно

| | |
|---|---|
| Компьютер | UEFI (все ПК примерно с 2012 года), 64-битный процессор, 4 ГБ ОЗУ, **30 ГБ+ свободного места** (лучше 60+) |
| Процессор | По умолчанию нужен Intel Haswell (2013+) или AMD Ryzen. Для более старых — см. ниже «Сборка» |
| Видеокарта | NVIDIA, AMD или Intel — драйвер ставится сам. Старые NVIDIA (до GTX 16xx) работают на более медленном свободном драйвере |
| Флешка | 8 ГБ и больше (будет стёрта) |

Не поддерживаются: Legacy/BIOS-режим, Secure Boot (его нужно выключить), шифрование диска.

---

## 2. Получить установочный образ (ISO)

Готового образа пока нет — его собирают из этого репозитория. Нужен компьютер с Windows 10/11
(или любым Arch/CachyOS Linux), 60 ГБ места и интернет.

**На Windows.** В PowerShell **от администратора**: `wsl --install archlinux`, перезагрузись,
открой Arch (`wsl -d archlinux`) и создай пользователя. Дальше всё — внутри Arch:

```bash
git clone https://github.com/Nazarik322/donkibone-linux.git
cd donkibone-linux
sudo ./scripts/setup-build-env.sh     # один раз; на вопросы отвечай y
./build.sh                            # час и больше; результат: out/celestia-….iso
```

На Arch/CachyOS — те же команды в обычном терминале.

Процессор старше 2013 года? Перед `./build.sh` в файле `config.env` поставь
`CACHYOS_MARCH="generic"`.

---

## 3. Записать на флешку

- **[Rufus](https://rufus.ie):** выбери флешку и ISO → «Старт» → режим записи **«DD-образ»**.
- **[balenaEtcher](https://etcher.balena.io):** Flash from file → флешка → Flash.
- **Linux:** `sudo dd if=celestia-*.iso of=/dev/sdX bs=4M status=progress oflag=sync`
  (`/dev/sdX` — флешка, проверь через `lsblk`).

## 4. Подготовка компьютера

**В Windows** (если она есть):

- Сделай резервную копию важного.
- **Освободи место**, если ставишь на тот же диск: `Win+X` → «Управление дисками» → правый клик
  по `C:` → «Сжать том» (от 30 000 МБ). Получившееся «Не распределено» не форматируй.
- Если включено шифрование **BitLocker**, найди ключ восстановления
  ([aka.ms/myrecoverykey](https://aka.ms/myrecoverykey)): после установки Windows может один
  раз его попросить.
- Выключи **«Быстрый запуск»**: «Панель управления» → «Электропитание» → «Действия кнопок
  питания» → «Изменение параметров, которые сейчас недоступны» → снять галочку.

**В BIOS/UEFI** (вход: Del или F2 при включении):

| Настройка | Значение |
|---|---|
| Secure Boot | **Выключить** |
| Режим загрузки / CSM | **UEFI**, CSM выключен |
| SATA Mode | **AHCI** (не RAID) |

**Загрузка с флешки:** при включении открой меню загрузки и выбери флешку с пометкой UEFI.
Обычно: ASUS — F8, MSI/ASRock — F11, Gigabyte/Lenovo/Dell/Acer — F12, HP — F9.

## 5. Установка

1. В меню флешки выбери **«Установить Celestia»**. Если экран чёрный — перезагрузись и выбери
   «безопасная графика».
2. В окне **«Куда установить Celestia»** выбери место:

   | Строка | Что произойдёт |
   |---|---|
   | **Свободное место** | Celestia ставится в неразмеченное место. **Ничего существующего не меняется** — обычный выбор рядом с Windows |
   | **Раздел Linux** | Старый раздел Linux стирается, на его месте ставится Celestia |
   | **Предыдущая установка Celestia** | Разделы прошлой (или прерванной) установки стираются, Celestia ставится заново |
   | **Весь диск** | Диск стирается целиком. Предлагается только для дисков без Windows и без данных |
   | 🔒 | Windows, данные, загрузчик Windows, RAID, сама флешка. **Выбрать нельзя** |

   Перед записью показывается, что будет сделано; если что-то стирается — нужно ввести слово
   **ERASE**. Установщик проверяет диск заново перед записью и после неё убеждается, что
   остальные разделы не изменились.
3. Язык и часовой пояс → раскладка → имя пользователя и пароль → «Установить».
4. «Перезагрузить» и **вытащи флешку**.

## 6. После установки

| Что | Как |
|---|---|
| Меню приложений | Super (клавиша Windows) |
| Терминал / браузер / файлы | Super+T / Super+W / Super+E |
| Закрыть окно / блокировка | Super+Q / Super+L |
| Меню выключения | Ctrl+Alt+Delete |
| Смена раскладки | Alt+Shift |
| Все горячие клавиши | [список caelestia](https://github.com/caelestia-dots/caelestia#default-keybinds) |
| Свои настройки | `~/.config/caelestia/hypr-user.lua`, `hypr-vars.lua`, `shell.json` |

### Обновления

Система обновляется из интернета командой **`celestia-update`** (она обновляет и саму систему,
и рабочий стол). Если CachyOS как раз выпустил новую версию Qt, а рабочий стол под неё ещё
пересобирается, команда скажет подождать — обычно меньше часа.

Есть три канала обновлений; переключение: `sudo celestia-channel stable|beta|dev`.

| Канал | Для чего |
|---|---|
| `stable` | Проверенные версии (по умолчанию) |
| `beta` | Новое, что уже опробовано |
| `dev` | Свежие сборки разработки, возможны поломки |

Твои изменённые файлы настроек при обновлении не перезаписываются: новая версия кладётся рядом
как `ИМЯ.celestia-new`.

**Откат.** Перед каждым обновлением делается снимок системы. Если что-то сломалось: программа
**Btrfs Assistant** → «Snapper» → выбрать снимок → «Restore» → перезагрузка.

## 7. Если что-то пошло не так

| Проблема | Решение |
|---|---|
| Флешка не видна в меню загрузки | Выключи Fast Boot в BIOS, выбери пункт с «UEFI», запиши флешку в режиме DD |
| Ошибка Secure Boot при запуске флешки | Выключи Secure Boot |
| Флешка зависает, ничего не пишет | Процессор слишком старый — собери ISO с `CACHYOS_MARCH="generic"` |
| «Не найдено подходящего места» | Освободи 30+ ГБ в Windows («Сжать том») |
| Не видно дисков | В BIOS стоит SATA Mode RAID — переключи на AHCI (если Windows уже стоит, сначала найди, как сделать это безопасно) |
| Сразу грузится Windows, меню нет | Обновление Windows перехватило загрузку. Загрузи Celestia через меню загрузки BIOS и выполни `sudo celestia-refind --fix-order` |
| Пропало оформление меню | `sudo celestia-refind` |
| Чёрный экран после обновления | В меню выбери Celestia, нажми **F2** → «Recovery», войди и выполни `celestia-update`, либо откати снимок (п. 6) |
| Windows просит ключ BitLocker | Введи ключ восстановления — это бывает один раз |

## 8. Удаление Celestia

1. В Windows: `Win+X` → «Управление дисками» → удали разделы Celestia (без буквы диска, обычно
   2 ГБ + основной) → освободившееся место можно присоединить к `C:`.
2. Убери меню загрузки. PowerShell от администратора:
   ```powershell
   mountvol S: /s
   Remove-Item -Recurse S:\EFI\refind
   mountvol S: /d
   bcdedit /enum firmware      # найди запись "Celestia" и её {идентификатор}
   bcdedit /delete {идентификатор}
   ```
3. Перезагрузи — сразу загрузится Windows. (Если Celestia ставилась со своим EFI-разделом с
   меткой `CELESTIA`, удали и его.)
